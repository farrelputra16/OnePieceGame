# One Piece Street Fight

A One Piece and Street Fighter inspired fighting game featuring characters from the One Piece anime series, built with Next.js and React. 

## 🎮 Features

- **Character Selection**: Choose from Luffy, Sanji, and Zoro
- **Multiple Backgrounds**: Fight in different One Piece locations (Default, Dressrosa, Marineford, Wano)
- **Combat System**: Attack, block, jump and move mechanics


## 🎯 Game Rules

### Objective
- Reduce your opponent's health to 0, OR
- Have more health when the 30-second timer runs out

### Controls

#### Player 1
- **A** - Move Left
- **D** - Move Right
- **W** - Jump
- **J** - Attack
- **K** - Block

#### Player 2
- **←** (Left Arrow) - Move Left
- **→** (Right Arrow) - Move Right
- **↑** (Up Arrow) - Jump
- **Enter** - Attack
- **Shift** - Block

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm, yarn, pnpm, or bun
